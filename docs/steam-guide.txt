[h1]What this is[/h1]

An interactive map of The Lands Between and the Realm of Shadow that [b]fills
itself in as you play[/b].

Rest at a new Site of Grace and it lights up. Kill a boss, pick up a Golden
Seed, and they get a checkmark. Nothing to tick off by hand — it reads your save
file and keeps up on its own.

It runs entirely on your own PC. No website, no account, nothing uploaded.

[img]PUT_YOUR_SCREENSHOT_URL_HERE[/img]

[hr][/hr]

[h1]What it tracks[/h1]

[b]3,506 markers[/b], every one wired to the flag your save actually uses:

[list]
[*][b]413 Sites of Grace[/b]
[*][b]208 boss arenas[/b] — 189 named after the actual boss
[*][b]2,400 item pickups[/b] in [b]47 categories[/b] — Golden Seeds, Crystal
Tears, talismans, spirit ashes, cookbooks, bell bearings, whetblades, smithing
stones by tier, golden runes by tier, gloveworts, incantations, sorceries,
weapons, armour
[*][b]294 points of interest[/b] and 157 unnamed landmarks
[*][b]34 map fragments[/b], each showing the region it reveals
[/list]

Categories toggle independently, so you can show only Golden Seeds, or only what
you [i]haven't[/i] picked up yet.

[h2]How high up is it[/h2]

The single most useful thing on a 2D map of a very vertical game. Hover or click
any marker and it tells you its height.

Two markers a few pixels apart can be a cliff, a lift and a fifteen-minute
detour apart. The Forge of the Giants reads [b]1969 m[/b]; the bottom of the
Siofra River well reads [b]−482 m[/b]. Your own height sits in the character
panel to compare against — live, as you move.

[h2]The game's own icons[/h2]

Graces, catacombs, caves, churches, tunnels — drawn with the real sprites lifted
out of the game files, not coloured dots. It looks like the in-game map because
it [i]is[/i] the in-game map.

[h2]Four map layers[/h2]

The Lands Between, the Underground (Siofra / Ainsel / Deeproot), the Realm of
Shadow, and the DLC underground.

[hr][/hr]

[h1]English and Russian[/h1]

Marker names come from the game's own text, so everything reads exactly as it
does in-game: [i]The First Step[/i] / [i]Первый шаг[/i], [i]Church of Elleh[/i]
/ [i]Храм Элле[/i].

One button switches. Search matches both at once, so an English name off a wiki
still finds the right marker while the interface is in Russian.

[hr][/hr]

[h1]Setup[/h1]

You need [b]Elden Ring installed[/b], plus [url=https://nodejs.org]Node.js[/url]
and [url=https://python.org]Python[/url]. Windows 10/11, or Linux with Proton.

[quote]When installing Python, tick [b]"Add Python to PATH"[/b] on the first
screen. It is easy to miss and it is the most common thing that goes wrong. The
setup script checks for it and says plainly if it is absent.[/quote]

[olist]
[*]Download from [url=https://github.com/egormagurin/EldenRingMap]GitHub[/url]
(green [b]Code[/b] button, then [b]Download ZIP[/b]) and unzip it anywhere.
[*]Double-click [b]Setup.bat[/b]. It finds your game and extracts the map, the
icons and every item location. A couple of minutes.
[*]Double-click [b]Start Map.bat[/b]. Your browser opens with the map.
[/olist]

Leave the little black window open while you play. On Linux, run
[b]setup-linux.sh[/b] then [b]start-map.sh[/b] instead.

Setup only needs re-running after a game update.

[hr][/hr]

[h1]Using it[/h1]

[list]
[*][b]Drag[/b] to pan, [b]scroll[/b] to zoom
[*][b]Click a marker[/b] for its name, height and a manual check-off button
[*][b]/[/b] jumps to search
[*][b]◎[/b] latches [b]follow mode[/b] — the map keeps itself centred on you as
you ride, and switches layer when you go underground
[*][b]Hide found[/b] leaves only what you still have not collected
[/list]

The sidebar remembers everything between sessions: which categories are on,
which panels you folded, the map layer, even whether you collapsed the sidebar
entirely to give the map the full window.

[h2]On your phone[/h2]

Run [b]"Start Map.bat" --lan[/b]. It prints a second address like
[b]http://192.168.1.42:8099[/b] — open that on a phone or tablet for a second
screen beside you while you play.

[hr][/hr]

[h1]Optional: a dot that moves[/h1]

By default the map updates whenever the game saves — which Elden Ring does
constantly, so progress is never more than a few seconds stale. What it cannot
do is move your dot smoothly.

[b]Start Map LIVE.bat[/b] adds a player dot that glides with a facing arrow, and
a live height readout. It asks for administrator rights, because Elden Ring runs
elevated.

[quote][b]Read-only.[/b] It opens the game with read-only access. It cannot
modify the game and never touches your save.[/quote]

[quote][b]Offline play only.[/b] Anti-cheat objects to anything reading game
memory, on principle. If you play online, use the normal [b]Start Map.bat[/b] —
you lose only the moving dot. This mode is for offline or modded setups where
EAC is not running.[/quote]

Run [b]Check Live Mode.bat[/b] to test whether it can attach.

[hr][/hr]

[h1]Playing Elden Ring Reforged?[/h1]

Supported. Point [b]MODDIR[/b] in [b]Setup.bat[/b] at the mod folder and the
extractors read the mod's own items, text and map data over the game's — Rune
and Ember Pieces included. It reads [b]ER0000.err[/b] saves as well as
[b].sl2[/b].

[hr][/hr]

[h1]Is this safe?[/h1]

The normal mode is completely passive:

[list]
[*]It [b]opens your save for reading[/b] and never writes to it
[*]It never touches the game process and injects nothing
[*]It never connects to the internet
[/list]

Nothing for anti-cheat to see, and nothing that can corrupt a save.

The optional real-time mode reads the running game's memory. Still read-only and
unable to modify anything — but keep it to offline play, the same advice that
applies to any mod, FPS unlocker or speedrun timer.

[hr][/hr]

[h1]Why is there a setup step?[/h1]

Because the map art and the names belong to FromSoftware. Shipping them would
mean redistributing their work, so the tool reads them out of the copy of the
game you already own. Side effect: it always matches your game version, and mods
work.

[hr][/hr]

[h1]If something goes wrong[/h1]

[b]The window opens and closes instantly[/b]
Another copy is still running and holding the port. Close the other black
window, or end [b]node.exe[/b] in Task Manager.

[b]"Node.js not found" or "Python not found"[/b]
Reinstall with [b]Add to PATH[/b] ticked, then open a [i]new[/i] window — PATH
changes do not reach windows that were already open.

[b]"Could not find your Elden Ring install"[/b]
Set [b]GAMEDIR[/b] near the top of [b]Setup.bat[/b] to the folder containing
[b]eldenring.exe[/b]. In Steam: right-click Elden Ring, then Manage, then Browse
local files, and go into the [b]Game[/b] folder.

[b]The wrong character is shown[/b]
Pick the save from the sidebar. With real-time mode on it matches the running
character automatically.

[b]Markers show no height[/b]
Re-run [b]Setup.bat[/b] — heights come from the generated files.

[b]Anything looks wrong after a game update[/b]
Re-run [b]Setup.bat[/b].

The full list is on the [url=https://github.com/egormagurin/EldenRingMap]GitHub
page[/url].

[hr][/hr]

[h1]Honest limitations[/h1]

[list]
[*][b]Not every item is placed.[/b] 2,400 come from the game's map files; some
others are spawned by event scripts. Enemy drops are not included.
[*][b]Shadow of the Erdtree items are missing[/b] unless you own and have
installed the DLC. The DLC map layer, its graces and its bosses appear either
way.
[*][b]19 of 208 boss arenas[/b] have no recoverable name and say "Boss arena
near <place>" instead.
[*]A few interiors the game itself never maps (Roundtable Hold, some arenas) are
skipped.
[/list]
